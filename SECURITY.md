## Reporting a Vulnerability

If you find a bug or a security vulnerability in the plugin, 
you can report it in the Issues section by clicking "New Issue" and selecting "Type: BUG" and "Labels: SECURITY". 
Describe the vulnerability and click "Create". 
Once submitted, the vulnerability will be fixed in the current or future supported versions of the PureAuth plugin.
